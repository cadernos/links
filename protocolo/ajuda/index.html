Administração do protocolo · Miguel

Alterações em regras exigem aprovação editorial e registro de versão. A página pública é gerada a partir do arquivo no GitHub. O arquivo no Drive é mantido separadamente: uma alteração em um dos lugares não sincroniza automaticamente o outro. Confira ambas as versões após cada publicação.

HTML no Drive ↗Cópia com ID estável; confirme a atualização efetiva.Prompt mestre ↗Regras de governança e revisão do projeto.Registro de aprendizagem ↗Feedback, validações e decisões documentadas.Miniprompt ↗Instruções resumidas do projeto GPT.Fonte HTML no GitHub ↗Arquivo publicado pelo GitHub Pages após um commit.Verificar publicação ↗Confira se a execução de deploy foi concluída com sucesso.Fonte normativa em Markdown ↗Base textual; preserve o conteúdo e a hierarquia das regras.
